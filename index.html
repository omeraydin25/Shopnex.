Genel Bakış

Shopnex RESTful API'si, e-ticaret verilerinize programatik olarak erişmenizi sağlar. Tüm istekler HTTPS üzerinden yapılır ve JSON formatında yanıt döner.

Kimlik Doğrulama

API'ye erişmek için bir API anahtarı gereklidir. Bu anahtarı Dashboard > Ayarlar > API Anahtarları bölümünden oluşturabilirsiniz.

// Örnek bir ürün listeleme isteği GET https://api.shopnex.com/v1/products
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

Webhook'lar

Olay tabanlı bildirimler almak için webhook'ları yapılandırabilirsiniz. Örneğin, yeni bir sipariş oluştuğunda anlık bildirim alabilirsiniz.
